My loop for every feature 🔁

Nothing goes on the roadmap without these four steps. The order is the point.

  1. Size the opportunityFind the biggest gap in retention, engagement, economy or monetisation and estimate what closing it is worth.
  2. Write the hypothesisIf we change X, player behaviour Y moves, measured by metric Z, with guardrail G.
  3. Run a clean testAgree the baseline, sample size and duration with analysts before launch. Read results without attachment.
  4. Decide and roadmapShip, iterate or stop with the producer, and rank what’s next by the value it will create.

How I analyse and design

The four skills I use most when turning player behaviour into product decisions.

📈 Data analysis

Cohorts, funnels and KPIs: DAU, retention, ARPDAU and LTV. I query with SQL and read dashboards in Firebase Analytics, Grafana, Power BI and Tableau to find the biggest gaps in retention, engagement and monetisation. I also deconstruct top hybrid-casual games to learn what drives their retention.

🗺️ User journey analysis

I map the full player path from install through first-time experience, deep engagement and first purchase, then find where players drop off. My onboarding flows reduced early drop-off in new installs.

🧪 A/B test setup

Hypothesis, primary metric, guardrail, baseline, sample size and run length are agreed before launch, then results are read with the producer and analysts. Try the sizing tool above.

📐 Wireframes

Low-fidelity wireframes in Figma to align stakeholders fast: casino and idle RPG game flows, login and chest-reward screens, plus a food delivery app, a survey insights dashboard and a music app.
